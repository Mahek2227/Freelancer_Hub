## 📌 Project Overview

Freelancer Hub is a MERN stack web application designed to connect freelancers and clients on a single platform. Clients can post projects, while freelancers can browse opportunities and submit proposals in real time.

The platform provides secure authentication, project management, communication tools, and role-based dashboards for a complete freelancing workflow.

---

## 🚀 Features

### 👤 Client Features
- Register & Login
- Post New Projects
- Manage Projects
- View Freelancer Proposals
- Accept / Reject Proposals

### 💼 Freelancer Features
- Browse Available Projects
- Submit Proposals
- Track Proposal Status
- Real-Time Communication
- Manage Profile

### 🔐 General Features
- JWT Authentication
- Secure Password Hashing
- REST API Integration
- Responsive Design
- MongoDB Database
- Real-Time Chat using Socket.io
